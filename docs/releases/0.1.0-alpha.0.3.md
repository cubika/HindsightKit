# ProvenLoop 0.1.0-alpha.0.3

This Windows Design Partner evidence candidate adds the first supported
one-line installer and lowers the tested runtime minimum to Node.js 22.16.
It is distributed through GitHub Release tarballs; npm registry publication
is not required for the internal preview.

## Install

```powershell
irm https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.3/install.ps1 | iex
```

The immutable installer:

- checks Windows, Node.js, npm, and Copilot CLI;
- installs Node.js 22 through Winget when Node is missing and the user agrees;
- probes the required `node:sqlite` backup API;
- downloads the exact GitHub Release tarball and SHA-256 file;
- installs into `%LOCALAPPDATA%\ProvenLoopRuntime`;
- adds the stable command directory to the user PATH;
- registers the version-pinned Copilot marketplace and plugin;
- enables capture, worker, retrieval, and correction learning;
- runs passive Doctor;
- removes temporary files.

Install without automatic collection:

```powershell
& ([ScriptBlock]::Create(
  (Invoke-RestMethod `
    https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.3/install.ps1)
)) -NoAutoCollect
```

Install without retrieval or correction learning:

```powershell
& ([ScriptBlock]::Create(
  (Invoke-RestMethod `
    https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.3/install.ps1)
)) -NoLearning
```

## Supported environment

- Windows 10 or Windows 11 x64;
- Node.js `>=22.16.0 <23`;
- npm `>=11 <12`;
- GitHub Copilot CLI `1.0.82-0`.

Node.js 22.16 is supported because it provides the required
`DatabaseSync({ timeout })` and `sqlite.backup()` APIs. The installer verifies
the APIs directly instead of relying only on the version string.

## Known limitations

- M0 still requires retained Windows 10/11, provider-degradation, latency, and
  two-version upgrade evidence.
- The aggregate MVP gate remains No-Go until M0 and review evidence pass.
- The installer is Windows-only and does not bundle Node.js.
