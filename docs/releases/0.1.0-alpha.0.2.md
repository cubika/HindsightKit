# ProvenLoop 0.1.0-alpha.0.2

This is the corrected Windows Design Partner evidence-collection candidate
for GitHub Copilot CLI. It is a prerelease and is not yet M0-approved.

It includes the marketplace ref fix from `0.1.0-alpha.0.1` and fixes
PowerShell 5.1 MCP launch validation on non-C: drives.

## Install

Microsoft-internal preview users should install the exact GitHub Release
tarball. This avoids public npm and CFS mirror availability:

```powershell
npm install --global `
  "https://github.com/cubika/ProvenLoop/releases/download/v0.1.0-alpha.0.2/provenloop-cli-0.1.0-alpha.0.2.tgz" `
  --no-audit --no-fund
provenloop install
provenloop doctor
```

For checksum verification and upgrade/rollback instructions, see
[Alpha installation and operations](../alpha-installation.md).

Capture and the local worker are enabled automatically. To opt out:

```powershell
provenloop install --no-auto-collect
provenloop collection disable
```

## Included

- non-blocking Copilot Extension capture and durable local queue;
- background canonical SQLite ingestion;
- Work Episode, scoped retrieval, MCP Explain and Feedback;
- explicit Remember, Correct, Mute, Forget, Delete, and Purge controls;
- verified correction learning and lifecycle handling;
- daily privacy-safe M0 acceptance reports;
- passive Doctor and explicit `doctor --online`;
- install, upgrade, disable, uninstall, purge, and rollback support.

## Known limitations

- Supports Windows and GitHub Copilot CLI `1.0.82-0`.
- Requires Node.js `>=22.18.0 <23` and npm `>=11 <12`.
- Windows 10/11 acceptance, provider degradation, and remote two-version
  upgrade evidence are still being collected.
- M0 is blocked and the aggregate MVP decision is No-Go until retained
  evidence satisfies the release thresholds.
- No cloud synchronization, dashboard, additional agent adapters, or M3-M6
  automation is included.

Generated acceptance reports intentionally exclude raw prompts, code, tool
arguments, tool results, credentials, queue files, databases, and Session
files.
