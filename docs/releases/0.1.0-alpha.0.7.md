# ProvenLoop 0.1.0-alpha.0.7

This Windows Design Partner evidence candidate supersedes the failed
`0.1.0-alpha.0.6` publication attempt.

## Install

```powershell
irm https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.7/install.ps1 | iex
```

## Fixed

- Stabilized Windows-hosted integration validation by using controlled worker
  admission, a realistic asynchronous capture flush budget, and a 30-second
  budget for repeated MVP gate evaluation.

## Known limitations

- M0 still requires retained Windows 10/11, provider-degradation, latency, and
  two-version remote marketplace-upgrade evidence.
- The aggregate MVP gate remains No-Go until M0 and review evidence pass.
- The installer is Windows-only and does not bundle Node.js.
