# ProvenLoop 0.1.0-alpha.0.5

This Windows Design Partner evidence candidate includes the Copilot CLI
compatibility policy introduced in `0.1.0-alpha.0.4` and stabilizes the release
workflow on loaded Windows hosted runners.

## Install

```powershell
irm https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.5/install.ps1 | iex
```

## Supported environment

- Windows 10 or Windows 11 x64;
- Node.js `>=22.16.0 <23`;
- npm `>=11 <12`;
- GitHub Copilot CLI `>=1.0.71`.

The installer checks the required Copilot Plugin Marketplace, installation, and
enable/disable commands before it changes Copilot configuration. Copilot CLI
`1.0.82-0` and `1.0.83-4` are ProvenLoop-verified; later compatible versions
are allowed but Doctor reports their verification state.

## Known limitations

- M0 still requires retained Windows 10/11, provider-degradation, latency, and
  two-version upgrade evidence.
- The aggregate MVP gate remains No-Go until M0 and review evidence pass.
- The installer is Windows-only and does not bundle Node.js.
