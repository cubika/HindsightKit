# ProvenLoop 0.1.0-alpha.0.6

This Windows Design Partner evidence candidate hardens lifecycle operations
before the M0 evidence-collection period.

## Install

```powershell
irm https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.6/install.ps1 | iex
```

## Fixed

- New runtimes install into independent versioned slots. The installer verifies
  and uses the exact new command, then changes PATH only after the Copilot
  integration upgrade succeeds.
- A failed marketplace or plugin replacement restores the prior integration
  and preserves the prior runtime locator.
- Purge waits for active Extensions to acknowledge shutdown and fails without
  deleting data when that cannot be confirmed.
- Managed Copilot settings are validated before uninstall changes plugin
  registration, and operational locks and Copilot commands have finite
  timeouts.

## Known limitations

- M0 still requires retained Windows 10/11, provider-degradation, latency, and
  two-version remote marketplace-upgrade evidence.
- The aggregate MVP gate remains No-Go until M0 and review evidence pass.
- The installer is Windows-only and does not bundle Node.js.
