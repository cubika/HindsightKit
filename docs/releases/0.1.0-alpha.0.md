# ProvenLoop 0.1.0-alpha.0

This package was the initial evidence candidate and is superseded by
`0.1.0-alpha.0.1`.

Do not install this version. Real Copilot CLI verification found that its
marketplace source check relied on abbreviated list output and could disable
capture after a successful pinned installation.

Install the corrected candidate instead:

```powershell
npm install --global @provenloop/cli@0.1.0-alpha.0.1
```
