# ProvenLoop 0.1.0-alpha.0.4

This Windows Design Partner evidence candidate removes the artificial exact
Copilot CLI version lock. It is distributed through GitHub Release tarballs;
npm registry publication is not required for the internal preview.

## Install

```powershell
irm https://raw.githubusercontent.com/cubika/ProvenLoop/v0.1.0-alpha.0.4/install.ps1 | iex
```

The immutable installer verifies the Release SHA-256, installs the tarball
into `%LOCALAPPDATA%\ProvenLoopRuntime`, and checks the required Copilot Plugin
Marketplace, installation, and enable/disable commands before it changes
Copilot configuration.

## Supported environment

- Windows 10 or Windows 11 x64;
- Node.js `>=22.16.0 <23`;
- npm `>=11 <12`;
- GitHub Copilot CLI `>=1.0.71`.

`1.0.82-0` and `1.0.83-4` have completed ProvenLoop verification. Later
compatible versions are not blocked solely by their version number; Doctor
reports that they need ProvenLoop evidence. The Extension API remains
experimental, so incompatible runtime commands or the unsupported session-file
format fail with an explicit error.

## Known limitations

- M0 still requires retained Windows 10/11, provider-degradation, latency, and
  two-version upgrade evidence.
- The aggregate MVP gate remains No-Go until M0 and review evidence pass.
- The installer is Windows-only and does not bundle Node.js.
